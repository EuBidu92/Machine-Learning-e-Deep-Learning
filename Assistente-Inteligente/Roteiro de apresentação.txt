# Assistente Inteligente com LangGraph, LangChain e Ollama

**Duração estimada: 5 minutos**

### Parte 1 — Introdução (40 segundos)

Bom dia!

O projeto que desenvolvi consiste em um assistente inteligente capaz de receber perguntas e encaminhá-las automaticamente para agentes especializados.

O sistema possui dois agentes: um especializado em programação Python e outro responsável por perguntas de conhecimentos gerais.

O diferencial é que a escolha do agente não depende de palavras-chave programadas manualmente. Essa decisão é realizada por um modelo de linguagem, utilizando inteligência artificial.

### Parte 2 — Tecnologias utilizadas (50 segundos)

O projeto foi desenvolvido utilizando Python como linguagem principal.

Utilizei o Ollama para executar localmente o modelo de linguagem Llama 3.2 3B, sem depender de uma API externa para gerar respostas.

O LangChain foi utilizado para integrar o modelo de linguagem à aplicação e organizar as mensagens enviadas aos agentes.

Já o LangGraph foi responsável pela construção e pelo gerenciamento do fluxo de execução.

A aplicação funciona diretamente no terminal e foi organizada em módulos separados para facilitar a manutenção e os testes.

### Parte 3 — Arquitetura e funcionamento (1 minuto)

Quando o usuário digita uma pergunta, ela é enviada ao classificador.

O classificador utiliza o Llama 3.2 3B para analisar o conteúdo e retornar uma das duas categorias possíveis: Python ou Geral.

Essa classificação é retornada em formato JSON, seguindo uma estrutura previamente definida.

Em seguida, o LangGraph utiliza uma aresta condicional para encaminhar a pergunta ao agente correspondente.

O agente especializado processa a pergunta utilizando o modelo de linguagem e devolve uma resposta ao usuário.

Para implementar esse fluxo, utilizei os recursos TypedDict, StateGraph, add_node, add_edge, add_conditional_edges, compile e invoke.

### Parte 4 — Demonstração prática (1 minuto e 30 segundos)

Agora vou demonstrar o funcionamento do sistema.

Primeiro, vou executar o arquivo principal, que inicia a interface interativa.

Vou perguntar como criar uma função em Python. O classificador deverá selecionar o agente Python, que apresentará uma explicação e um exemplo de código.

Depois, vou fazer uma pergunta de conhecimentos gerais, como qual é a capital da Argentina.

Nesse caso, o classificador deverá selecionar o agente Geral.

Também desenvolvi testes automatizados para verificar o comportamento do classificador e a integração entre os componentes.

### Parte 5 — Resultados e conclusão (1 minuto)

Durante o desenvolvimento, encontrei dificuldades na classificação das perguntas utilizando inicialmente o modelo Llama 3.2 1B.

O modelo frequentemente retornava respostas fora do formato esperado ou selecionava categorias incorretas.

Para melhorar o funcionamento, implementei a classificação estruturada em JSON e passei a utilizar o modelo Llama 3.2 3B.

Nos testes realizados, o classificador obteve 20 acertos em 20 perguntas.

Também executei quatro testes de integração, todos concluídos corretamente.

Esses resultados demonstram que a arquitetura desenvolvida está funcional para os cenários avaliados.

Como possibilidade de evolução, o projeto poderá receber novos agentes especializados, histórico de conversas e uma interface gráfica.

--------------------------

Possíveis perguntas do professor
Pergunta	Resposta recomendada
Por que utilizar LangGraph?	Para organizar a execução dos agentes por meio de um grafo com decisões condicionais.
Qual é a função do LangChain?	Integrar o modelo de linguagem e estruturar a comunicação com os agentes.
Por que utilizar Ollama?	Para executar a LLM localmente, sem depender de uma API externa.
Por que utilizar dois agentes?	Para separar responsabilidades e permitir instruções especializadas.
Como o sistema escolhe o agente?	Uma LLM classifica a pergunta e retorna a categoria em JSON.
O que acontece quando a classificação é inválida?	O classificador tenta novamente e, se não conseguir uma categoria válida, gera um erro controlado.
Por que trocar o Llama 3.2 1B pelo 3B?	Porque o modelo 1B apresentou dificuldades nos testes, enquanto o 3B obteve resultados melhores.
O sistema pode responder incorretamente?	Sim. As respostas são geradas por uma LLM e podem conter imprecisões.
